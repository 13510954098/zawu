# Lanerc 本地测试记录器

原生 Java / Android API，无第三方运行时依赖。最低 Android 11（API 30），目标 API 34，编译 API 35。无 Google 服务、root、ADB、网络权限、音频权限、存储权限、统计或广告 SDK。仅用户自愿操作目标应用，不执行点击或奖励操作。

## 安装与操作

1. 下载 `lanerc-local-recorder-debug.apk`，对照随附 `SHA256SUMS.txt`。在文件管理器中打开，按系统提示允许该来源安装。Debug 签名仅适合测试，不用于生产发布。
2. 打开“Lanerc 本地记录器”。可先选择“授权无障碍”，在系统设置中开启本记录器；确认服务显示已连接。可选开启悬浮窗。Android 13+ 可允许通知；某些厂商也需允许前台通知/后台运行。Android 13+ 侧载无障碍可能需在应用信息菜单允许受限设置。
3. 点击“开始记录”，阅读敏感画面警告，选择申请屏幕授权或仅记录时间线。系统弹窗中确认后开始（Android 14 建议选择整个屏幕，单应用录制因系统实现可能有兼容限制）。拒绝录屏不会产生虚假的视频；仍可使用已授权的无障碍记录。无障碍未授权时仅有手动/系统时间线。
4. 应用尝试启动 `com.clggjv.xcjfmd.ffo`。未安装或无启动入口会提示；系统限制自动切换时请自行打开 Lanerc。自行播放广告/操作权益，记录器不代替用户操作。
5. 在输入密码或切换到私人应用前通过悬浮按钮或前台通知暂停；“暂停/继续”同时控制视频与无障碍采集。也可返回记录器控制。暂停状态见通知或应用状态。悬浮控件可能进入视频。
6. 点击“结束并导出”。先结束录制并封装 MP4，然后返回记录器填写备注（播放成功、次数前后变化、重启后是否保留等）。如果系统不允许自动打开界面，点结束通知或手动返回记录器。
7. 点击“导出 ZIP”，阅读隐私提示，在系统文件选择器中选择位置并“保存”。取消选择不会删除本地数据，导出失败可重试。先自行检查内容，再把 ZIP 上传到原对话请求分析；应用不会自动上传。
8. “一键删除”删除应用内本次原始文件和缓存 ZIP；系统保存位置/您分享出去的副本必须另外自行删除。不覆盖上次记录；需先导出或删除再开启下一次。

## ZIP 与隐私

- `report.txt`：环境、授权/启动状态、限制、用户备注。无硬件标识、Android ID、账号信息。
- `events.jsonl`：每行 JSON，含 ISO 时间和单调时钟时间，事件类型和脱敏详情；节点快照结构位于 detail 字符串内（可再 JSON 解码）。限制 150 节点/16 层，每秒采样；点击事件尽量单独采样；事件文件上限 16MiB。窗口/内容变化只是被动信号，不自动推断广告成功或奖励到账。
- `screen.mp4`：仅成功申请录屏并创建视频时存在；无麦克风/内部音频。视频上限 1280 像素长边、30fps、H.264。会话中不重建显示方向，旋转可能留边。视频暂停会压缩媒体时间，请按 video_started / video_paused / video_resumed 对齐墙钟时间。
- `recording-error.txt`：事件写入失败/超过上限时尽可能保留的原因。

无障碍只允许目标包事件，主动窗口也再次检查包名。密码/可编辑节点及其子树跳过。不保存任何节点文本、描述、类名、资源 ID 或事件文字，从源头避免常见账号/令牌泄露；只保留坐标、层级、可点击状态和子节点数。应用外置广告窗口可能故意被过滤，Flutter/自绘/安全窗口可能只有少数节点。**不能声称读到 Flutter 全部节点或私有数据。**

**录屏不做内容脱敏。** 其他应用、键盘、账号和通知可能进入画面，暂停由用户控制。普通 Android MediaProjection 没有可靠的第三方安全窗口检测回调，受 FLAG_SECURE 保护的画面可能黑屏；不能自动辨认“安全窗口”与普通黑色画面。报告明确标注需要人工核对，未假装已经捕获受保护内容。不读取目标私有文件、完整 logcat 或 HTTPS 明文。

系统撤销录屏时停止会话；磁盘不足 64MiB 时尝试提前结束，每 3 秒检查，不能保证所有低空间情况下都成功封装。视频/封装/导出失败保留可用文件和错误。强制停止、进程被杀、掉电仍可能损坏 MP4；重新打开可以导出之前记录，报告标记未正常结束。应用仅保留一个会话；备份被禁用。

## 构建

JDK 17、Gradle 8.9、Android SDK platform 35 / build tools 35.0.0：

```sh
cd recorder
./gradlew :app:assembleDebug :app:lintDebug
```

仓库给出完整 Gradle 配置与官方 Gradle 8.9 wrapper；CI 也用 setup-gradle 固定版本。源码编译需要下载 Android/Gradle 工具，但安装后的应用不联网。

GitHub Actions：`.github/workflows/build-recorder.yml`。构建产物 `lanerc-local-recorder-debug` 含 APK 和 SHA-256；单独保存 lint 报告。Android 11 模拟器作业使用 **AOSP default API 30（非 Google Play 镜像）** 和无第三方测试库的 instrumentation。测试失败不会掩盖 APK 构建结果。

## 测试边界

设备端冒烟脚本覆盖：拒绝屏幕授权后无视频、报告/时间线 ZIP；授权录屏；暂停/继续；通过 AOSP 测试镜像的 root shell 调用系统服务撤销录屏（仅 CI，安装后的应用不使用 root/ADB）中断；检查 MP4 存在且非空和 ZIP 条目。**脚本存在不等于已通过**，实际运行结果见 Actions 与 `TESTING.md`。

必须真人在 Android 11 / 厂商设备补测：目标 Lanerc 的实际广告/权益行为、无障碍节点可用性与密码字段、安全窗口视觉限制、悬浮窗/通知点击、系统文件选择器保存后 ZIP 可打开、低空间、强杀/恢复、旋转、拒绝所有权限、长时间录制。测试脚本不检查奖励或权益是否真实变化，也不伪造这些数据。
